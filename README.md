One word for your Wi-Fi: **Microwaved** — press start on the microwave and the Wi-Fi dies on the spot. A running microwave floods the 2.4 GHz band and knocks home Wi-Fi out; everyone who has heated leftovers during a video call has lived it. The program writes that one word to `/output/entry.txt` for the judge.

## Run it

```sh
node main.ts
```
